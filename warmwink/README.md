# Warmwink

Launch assets for a UK self-heating steam eye mask brand. Unrelated to the editor app in this repo; kept here so the files persist.

- `launch-kit.html` – the plan: 7-day checklist, pricing, suppliers, Shopify setup, legal, social, ads, emails
- `store/storefront.html` – storefront design and copy
- `shopify/` – product import CSV (12 variants), policies, pages, homepage copy
- `brand/` – logo files
- `social/` – eight 1080×1350 post graphics
